## Demo Flow to Script

1. Open app → landing page
2. Create a campaign (use a scenario from CAMPAIGN_EXAMPLES.md)
3. Generate a brief — note whether Gemini or mock mode is active
4. Review and edit one brief field
5. Find ranked creators — point out scores, evidence, badges
6. Highlight an unavailable creator (amber badge) and an over-budget creator (red badge)
7. Shortlist two creators
8. View campaign summary and status
9. Mark campaign as complete
